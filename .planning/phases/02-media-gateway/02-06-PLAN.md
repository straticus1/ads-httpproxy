<threat_model>
Trust boundary and STRIDE disposition: TURN credentials cross from tenant API to an independently allocating backend. Mitigate amplification/open relay with authentication, peer deny rules and partitions; quota bypass by username refresh with backend total caps; secret disclosure with no-store/redaction; revoked credential reuse by explicit measured lifetime semantics rather than false teardown guarantees.
All listed threats are mitigated by the tasks and negative tests in this plan; backend packet/protocol implementation is transferred to the pinned upstream service, but authorization and release verification remain ADS responsibilities. No acceptance of a high-severity open relay, tenant escape or leaked cryptographic material is permitted.
</threat_model>
